Starting from KubeVirt v1.9, all Beta feature gates are enabled by default . This is a significant behavioral change from previous versions, where Beta features had to be explicitly opted into. If you are a downstream vendor, cluster administrator, or anyone deploying KubeVirt in production, please read on to understand what this means and how to prepare.
